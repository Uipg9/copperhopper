# Copper Hopper

A Fabric mod for Minecraft 26.3. Adds the **Copper Hopper**: it works exactly like a vanilla hopper
(5 slots, pulls from containers and dropped items above, pushes into the container it faces, locks
with redstone, comparator output, same menu) but moves items at **half speed** (one item every
16 ticks instead of 8).

Recipe: the hopper shape with 5 copper ingots and a chest. Creative tab: Redstone Blocks, after the hopper.

Requires Fabric API.
